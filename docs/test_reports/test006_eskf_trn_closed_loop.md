# TEST-006: Recursive ESKF + TRN closed-loop validation

## Dataset
- Bag: `data/flight001`
- Duration: 1049.2 s
- Vehicle: PX4 SITL fixed-wing Cessna
- IMU: `/fmu/out/sensor_combined` at ~100 Hz
- Reference: `/fmu/out/vehicle_local_position`

## Terrain setup
- Synthetic fractal terrain map generated by `tools/generate_terrain.py`
- For this validation test, world terrain and onboard database are intentionally consistent:
  smoothed terrain = measurement-generating world = onboard map database.
- Purpose: isolate and validate ESKF/TRN math without map-reality mismatch.

## Filter
- Nominal strapdown INS propagated at IMU rate.
- Error-state Kalman filter with position, velocity, attitude error, accel bias, gyro bias.
- TRN scalar update at ~2 Hz using terrain height residual.
- Measurement Jacobian from local terrain slope.
- Integrity measures:
  - Innovation gate
  - Terrain slope observability gate
  - State-jump limiting
  - Positive-definite covariance repair

## Result
Accepted updates: 2058  
Gated updates: 38  
Flat-skipped updates: 3  

Horizontal error over 60-300 s:

| System | RMS error | Max error |
|---|---:|---:|
| Unaided calibrated INS | 2259.3 m | 5058.2 m |
| ESKF + TRN | 34.6 m | 107.4 m |

## Conclusion
Recursive TRN-aided ESKF bounded inertial drift and achieved ~65x RMS improvement
over unaided INS on the validation dataset. This proves the closed-loop navigation
core concept. Next test must reintroduce map-reality mismatch and evaluate robustness.
